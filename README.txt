PORTFÓLIO PROFISSIONAL — LUIZ EDUARDO

ARQUIVOS
- index.html -> conteúdo do site
- style.css  -> visual e responsividade
- script.js  -> interações, tema, menu, filtros e animações
- assets/    -> coloque fotos e imagens dos projetos aqui

COMO ABRIR
1. Extraia a pasta.
2. Dê dois cliques no arquivo index.html.
3. O site abrirá no navegador.

COMO COLOCAR SUA FOTO
1. Salve sua foto como assets/perfil.jpg
2. No index.html, procure por:
   <div class="profile-photo">
3. Troque o conteúdo da div por:
   <img src="assets/perfil.jpg" alt="Foto de Luiz Eduardo">

COMO ADICIONAR LINKEDIN, GITHUB E E-MAIL
No fim do index.html, na seção Contato, substitua os href="#" pelos seus links.

Exemplo:
<a href="mailto:seuemail@exemplo.com">E-mail</a>
<a href="https://www.linkedin.com/in/SEU-USUARIO">LinkedIn</a>
<a href="https://github.com/SEU-USUARIO">GitHub</a>

COMO PUBLICAR GRATUITAMENTE
O site é estático e pode ser publicado em serviços como:
- GitHub Pages
- Cloudflare Pages
- Netlify
- Vercel

OBSERVAÇÃO
A fonte principal usa Google Fonts. Se estiver sem internet, o site continua funcionando
com fontes do sistema.
